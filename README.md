# Trang nhóm và portfolio thành viên

```
index.html          trang chủ nhóm (hiện avatar các thành viên)
style.css
tuan/               portfolio của Phạm Tuân
mau/                bản mẫu trống để thành viên sao chép
thanh-vien-2 ... 5/ thư mục của từng bạn (đổi tên thành tên bạn, ví dụ "an")
```

## Mỗi thành viên làm gì
1. Chỉ sửa thư mục của mình, không sửa thư mục người khác (đỡ xung đột khi gộp code).
2. Mở `index.html` trong thư mục của mình, thay chữ mẫu bằng thông tin thật, bỏ ảnh `avatar.jpg` vào cùng thư mục.
3. Trong `index.html` của trang nhóm: đổi tên, vai trò, link thư mục và dòng `<img src="...">` cho đúng người.

## Đưa lên GitHub Pages
1. Đưa toàn bộ thư mục này lên repo chung.
2. Settings, Pages, Branch `main`, thư mục `/ (root)`, Save.
3. Link nhóm có dạng `https://<tên-tài-khoản>.github.io/<tên-repo>/`.
